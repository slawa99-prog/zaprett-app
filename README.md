Приложение разработано для работы с модулем [zaprett](https://github.com/egor-white/zaprett)
> [!IMPORTANT]
> 📢 [Официальный Telegram-канал приложения](https://t.me/zaprett_module)

> [!CAUTION]
> ⚠️ Для корректной работы приложения **желательны root-права**, однако предусмотрен режим без root на основе **byedpi**

---

На данный момент приложение умеет:
* Запускать, останавливать и перезапускать сервис
* Работа с листами (добавление, включение и выключение, загрузка из репозитория)
* Работа с айписетами (добавление, включение и выключение, загрузка из репозитория)
* Работа с стратегиями (добавление, выбор, загрузка из репозитория)
* Авто обновление приложения

### Подбор стратегии в форке

В режиме root с модулем `zaprett` выберите `nfqws` и откройте вкладку
«Стратегии». Приложение уже содержит каталог из 30 готовых стратегий,
четыре необходимых bin-файла и список доменов YouTube, взятые из
`CherretGit/zaprett-repo`. При первом открытии вкладки файлы автоматически
копируются в хранилище, без загрузки из сети. Среди них `strategy-alt11`.
Кнопка «Подобрать и включить» в этой же вкладке сразу начнёт проверку.
Существующие файлы не перезаписываются. Для `nfqws2` в исходном каталоге пока
нет готового набора, поэтому встроенный каталог доступен в `nfqws`.

Проверка сравнивает до 12 доменов сначала без запущенного сервиса, затем с
каждой стратегией. Один запрос может ждать до шести секунд; любой ответ HTTP
означает, что DNS, TCP и TLS сработали. Стратегия применяется, только если она
улучшила базовый результат. Ошибки запуска и тип сетевой ошибки отображаются
отдельно. Сверху показаны число проверенных стратегий и общий ход подбора.
Успешные результаты по мере проверки поднимаются вверх по проценту доступных
HTTPS-адресов. Список можно прокручивать стрелками пульта и во время проверки.

Проверка HTTPS не подтверждает воспроизведение видео в SmartTube или YouTube.
После подбора проверьте нужные приложения на приставке. Это пока перебор готовых
вариантов, а не индивидуальный поиск параметров `blockcheck`.

Вкладка «Стратегии» также показывает переключатель «Запускать zaprett при
включении приставки». Он сохраняет настройку в модуле Magisk: после загрузки
Android модуль запускает выбранную стратегию и далее перезапускает сервис раз
в час. Результат проверки показан числом доступных HTTPS-адресов, например
«5 из 6 (83%)»; это не ход загрузки файла.

Тестовая сборка имеет отдельный идентификатор `com.slawa99.zaprett.auto` и
устанавливается рядом с исходным приложением. Обе программы обращаются к одному
модулю `zaprett` и его настройкам: не запускайте перебор в двух приложениях
одновременно. Обновление от автора исходного приложения и его Firebase в
тестовой сборке отключены.
