# Zapret Pocket v73-sv1 / SV Pocket 1.2.10

Тестовая редакция для Magisk. База — официальный релиз sevcator 73; https://github.com/sevcator/zapret-pocket/releases/tag/73 . Движки обеих версий, DNSCrypt, четыре обновлённых Lua-скрипта, все 300 профилей и поставляемый список из 54 175 записей взяты из официального ZIP без изменений. Модуль сохраняет id zapret, versionCode 73 и адрес обновлений sevcator для Magisk. Каталог SV Pocket этим файлом не публикуется.

## Что перенесено и добавлено

Перенесены исправления SV3: тестер загружает библиотеки zapret2 как сервис, сохраняет исходную стратегию и убирает созданные для теста процессы; проверка готовности и безопасная остановка процессов, восстановление соединения, Android curl без внешнего libz.so.1 для четырёх архитектур, проверка сертификатов, локальные списки для запуска и отдельное обновление списков после загрузки. Порог и длительность сетевых проверок не менялись.

Установщик допускает новую установку, проверенные штатные v72/v73, v72-sv1/sv2/sv3 и повторную установку v73-sv1. При переходе сохраняет выбранную стратегию, локальные профили, пользовательские списки, настройки DNS и режим быстрого старта. Если старый IP-список в точности штатный из v72 и источник штатный, применяется встроенный список v73. Свой явно настроенный источник или изменённая копия сохраняются. Неполные двоичные компоненты или отсутствующая базовая Lua-библиотека прерывают установку. Отключённый, удаляемый, ожидающий перезагрузки или неизвестный модуль не мигрируется. Процессы, PID и блокировки старой версии не переносятся. Повторного перемонтирования /data нет. При чистой установке системные настройки применяются после подготовки модуля; при ошибке PackageManager сохраняется предусмотренная модулем резервная установка VpnHotspot.

## Установка и проверка

1. На тестовой приставке дождитесь окончания подбора и видеотеста. Запишите исходное название стратегии; если после предыдущей установки Magisk просит перезагрузку, сначала перезагрузитесь.
2. Установите APK SV Pocket 1.2.10 поверх старого приложения. В Magisk выберите «Модули» → установку ZIP из памяти. Старый модуль не удаляйте. После успешной установки перезагрузите приставку.
3. Проверьте автоматический запуск, сохранённую стратегию и воспроизведение в YouTube и SmartTube. Для рейтинга на новой версии запустите новый подбор: результаты другой версии/редакции не подтверждают воспроизведение после обновления. Сначала протестируйте на одной приставке. Старая сборка v72-sv3 не предназначена для установки поверх v73.
4. Для сравнения провайдеров проверяйте одни и те же ролики в одной и той же сети на каждой версии. Проверка целостности файлов и моделирование установки не заменяют реальную проверку сети и Magisk на Tanix.

## Воспроизводимая сборка

Из этой директории в репозитории: `python3 build.py zapret-pocket-73.zip Zapret-Pocket-v72-SV3.zip Zapret-Pocket-v73-SV1.zip`. Вместо SV3 можно передать оригинальный подписанный SV-Pocket-1.2.8.apk. Сборка проверяет SHA-256 обоих входов и всех четырёх curl. Текстовый v73-sv1.patch — полный diff относительно официального v73, включая изменения предыдущих SV; рецепт сборки curl и лицензии сохранены в META-INF/sv-pocket/. Источники APK: https://github.com/slawa99-prog/zaprett-app .
