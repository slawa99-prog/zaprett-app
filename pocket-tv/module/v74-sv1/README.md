# Zapret Pocket v74-sv1 / SV Pocket 1.2.11

Тестовая сборка для Android TV и Magisk на основе [Pocket 74 от sevcator](https://github.com/sevcator/zapret-pocket/releases/tag/74). Использует все 300 исходных профилей, включая 125 для zapret2, движки v74 для всех четырёх архитектур, Lua и DNSCrypt из официального ZIP. Встроенная база содержит 54 267 IP-записей и новые штатные правила Discord. Из v73-sv1 перенесены загрузка Lua в тестере, восстановление сервиса и исходной стратегии, проверка процессов, автономный Android curl с проверкой сертификатов и фоновое обновление списков. Длительность проб и правила видеотеста прежние.

## Установка на тестовую приставку

1. Дождитесь окончания подбора или видеотеста. Установите подписанный SV Pocket 1.2.11 поверх 1.2.10. Если Magisk уже ожидает перезагрузку после других изменений, сначала перезагрузитесь.
2. В Magisk выберите «Модули» → «Установить из памяти» и ZIP v74-sv1. Не удаляйте предыдущий модуль. После успешной установки перезагрузитесь. Сохранённая стратегия используется сразу, пересчитывать 300 результатов для просмотра не требуется.
3. Откройте YouTube или SmartTube до входа в SV Pocket и проверьте реальное воспроизведение. Для нового рейтинга и видеотеста нужен подбор на новой версии. Переход между штатным модулем и SV также требует нового рейтинга.
4. Для сравнения с v73-sv1 проверьте на одной приставке и в одной сети одинаковые ролики и стратегию; сравните время до первого кадра и остановки на буферизацию. Автоматические проверки не измеряют сеть реального провайдера. Старый установщик v73-sv1 не предназначен для установки поверх v74.

## Миграция

Поддерживаются штатные v72, v73, v74, редакции v72-sv1/sv2/sv3, v73-sv1 и повторная установка этой редакции. Установщик работает в каталоге подготовки Magisk и проверяет версию и известные скрипты. Настройки, выбранная стратегия, свои профили, списки, режим быстрого запуска сохраняются. Неизвестная редакция, незавершённая операция или неподходящий комплект прерывают установку. Каталог для клиентов не меняется. Сохраняются id zapret, versionCode 74 и штатный updateJson sevcator для Magisk.

При штатном источнике точные встроенные IP-базы v72/v73 заменяются новой. Скачанная или изменённая база и свой источник сохраняются. Для штатного DNS обновляется только известная исходная основа правил: отдельный пользовательский файл и всё после штатной метки сохраняются. Для своего DNS-источника или вручную изменённой основы сохраняется установленный файл.

## Воспроизведение сборки

Из этой директории: `python3 build.py zapret-pocket-74.zip Zapret-Pocket-v73-SV1.zip Zapret-Pocket-v74-SV1.zip`. Вместо старого ZIP разрешён оригинальный подписанный SV-Pocket-1.2.8.apk. Сверяются SHA-256 обоих входов и всех четырёх curl. Полный патч к официальному v74, лицензии и рецепт curl находятся также в META-INF/sv-pocket/. Исходники приложения: https://github.com/slawa99-prog/zaprett-app .

Проверка установщика без доступа к сети или root: `python3 test_migration.py --module Zapret-Pocket-v74-SV1.zip --stock72 zapret-pocket-72.zip --stock73 zapret-pocket-73.zip --stock74 zapret-pocket-74.zip --sv73 Zapret-Pocket-v73-SV1.zip`. Вызывается упакованный установщик во временном каталоге с имитацией интерфейсов Magisk; воспроизведение этим не проверяется.
